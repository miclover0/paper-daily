## 修复 GitHub push 失败问题
- **根因分析**：两个问题叠加
  1. git 全局代理 `http://127.0.0.1:7897`（用户 Clash/代理工具），但自动化任务在 23:00 运行时代理进程未启动
  2. `GITHUB_TOKEN` 环境变量自动化任务中为空（不继承用户 shell 环境）
- **修复方案**：改用 SSH 认证
  - 生成 SSH key：`~/.ssh/id_ed25519`（ed25519 类型，注释 miclo-paper-daily-auto）
  - 创建 `~/.ssh/config`，配置 `ProxyCommand none` 绕过代理
  - 仓库 remote 切换为 `git@github.com:miclover0/paper-daily.git`
  - 更新自动化任务 prompt，移除 HTTPS/Token 逻辑
- **验证成功**：用户已添加公钥，`ssh -T git@github.com` → "Hi miclover0!" ✅
- **补推成功**：4 个积压 commit (6/9~6/12) 全部通过 SSH 推送到 GitHub，GitHub Pages 已更新
- **问题彻底解决**：自动化任务后续直接 `git push origin main` 即可正常运行
