A1 Trained Agentic Context Management

arXiv: 2610.02404 OpenAIQwenAgent

📝 中文摘要（中英对照）：

We study long context language models. 我们研究长语境语言模型。

Instead of training long context natively, or designing a long context harness, we train a model over the simplest possible harness: a tool to call itself with any specified prompt and a tool to read tokens in a range from the input context. 我们不是本地训练长上下文，也不是设计长上下文线束，而是在最简单的线束上训练模型：使用任何指定提示调用自身的工具，以及从输入上下文中读取令牌的工具。

We finetune Qwen3.6-35B-A3B on a diverse synthetic dataset using this harness. 我们在使用此线束的多样化合成数据集上微调Qwen3.6-35B-A3B。

With only 8,000 tokens of context, our small model is as strong as GPT-5.4 with 1M tokens of context on the OOLONG-synth benchmark when document length exceeds 40K tokens. 只有8,000个上下文令牌，当文档长度超过40K个令牌时，我们的小型模型与GPT-5.4一样强大，在OOLONG合成基准上具有100万个上下文令牌。

A2 DeReAct: Decomposed Reasoning and Acting for Reliable AI Agents

arXiv: 2610.02351 AnthropicQwenAgent

📝 中文摘要（中英对照）：

ReAct-based agents typically rely on a single LLM policy to propose actions, interact with the environment, and decide when a task is complete. 基于ReAct的代理通常依靠单个LLM策略来建议操作、与环境交互并决定任务何时完成。

This coupling makes action authorization and completion control difficult to enforce independently, allowing errors to propagate and unsupported completion claims to terminate execution. 这种耦合使得操作授权和完成控制难以独立实施，从而允许错误传播和不受支持的完成声明终止执行。

We introduce DeReAct, a modular agent architecture that externalizes two gating policies: a Critic that validates proposed actions before execution, and a Context Manager that reconstructs an environment-supported \textsc{State} and certifies task completion. 我们引入了DeReAct ，这是一种模块化代理架构，它将两个门控策略外化：在执行之前验证建议操作的Critic ，以及重构环境支持的\ textsc {State}并证明任务完成的Context Manager。

Across GAIA and SWE-bench Verified, DeReAct improves Pass@1 most for weaker Brain models, with gains of 6.5--7.0 points for Qwen3-Coder-480B and 4.2--5.2 points for Claude Sonnet~4.5; gains diminish as Brain capability increases. 在GAIA和SWE-bench Verified中， DeReAct对较弱Brain模型的Pass @ 1提升幅度最大， Qwen3-Coder-480B提升6.5--7.0分， Claude Sonnet ~4.5提升4.2--5.2分；随着Brain能力的提升，提升幅度减小。

Trajectory and ablation analyses show that external gating is effective when targeted failures are sufficiently prevalent and the gating policy is itself sufficient. 轨迹和消融分析表明，当目标故障足够普遍且门控策略本身就足够时，外部门控是有效的。

With Claude Opus~4.5, Pass@1 remains comparable to ReAct, while DeReAct produces more evidence-complete and constraint-satisfying trajectories, indicating that completion control can trade earlier termination for stronger grounding. 在Claude Opus~4.5中， Pass @ 1仍然可以与ReAct相媲美，而DeReAct产生了更多的证据完整和约束满足的轨迹，这表明完成控制可以用更早的终止来换取更强的接地。

Overall, DeReAct improves weaker agents while retaining grounding benefits as models strengthen. 总体而言，随着模型的加强， DeReAct可以改善较弱的代理，同时保留接地优势。

A3 Threat-Preserving Representation Sensitivity in Agent-Security Benchmarks

arXiv: 2610.03585 OpenAIAnthropicAgent

📝 中文摘要（中英对照）：

Security benchmarks for LLM-based agents often report the attack success rate (ASR) as a measure of model robustness and use these scores to compare different models and defense mechanisms, assuming that they describe the security of the agent. 基于LLM的代理的安全基准通常将攻击成功率（ ASR ）报告为模型鲁棒性的度量，并使用这些分数来比较不同的模型和防御机制，假设它们描述了代理的安全性。

In this paper, we explore whether it also influences the benchmark's measurement. 在本文中，我们将探讨它是否也会影响基准的测量。

To measure the effect of the benchmark representation, we introduce threat-preserving representation sensitivity (TPRS), which measures how much the ASR changes when we change the agent-visible representation while holding the underlying task, harmful action, security policy, ground truth, environment, and the evaluation criteria fixed. 为了衡量基准表示的效果，我们引入了威胁保留表示敏感性（ TPRS ） ，它衡量当我们更改代理可见表示时ASR的变化程度，同时保持基础任务、有害行为、安全策略、地面真相、环境和评估标准固定。

On Agent Security Bench (ASB), replacing threat-related tool names with threat-neutral names raises the committed attack success rate by 11.67 percentage points on GPT-5-mini and by 13.21 points on Claude Haiku 4.5. 在Agent Security Bench （ ASB ）上，将威胁相关工具名称替换为威胁中立名称，可使GPT-5-mini的承诺攻击成功率提高11.67个百分点， Claude Haiku 4.5提高13.21个百分点。

On MCPTox, replacing the original neutral tool name with an explicit threat-related name lowers the ASR by 11.00 percentage points on GPT-5-mini and 4.11 points on Claude Haiku 4.5. 在MCPTox上，用明确的威胁相关名称替换原始中立工具名称，可使GPT-5-mini的ASR降低11.00个百分点，使Claude Haiku 4.5的ASR降低4.11个百分点。

On AgentDojo, adding threat-related wording to the attack-relevant tool changes ASR by only 0.50 percentage points on GPT-4o-mini, yet the benign utility falls by 5.36 points on tasks requiring that tool. 在AgentDojo上，在攻击相关工具中添加与威胁相关的措辞只会使GPT-4o-mini的ASR降低0.50个百分点，而在需要该工具的任务上，该良性效用降低了5.36个百分点。

We ran an experiment on MCPTox where we observed that a threat-neutral name matched on token count, length, and casing reproduces most of the shift produced by the threat-explicit name (8.54 of 11.00 points on GPT-5-mini). 我们在MCPTox上进行了一项实验，观察到在令牌计数、长度和大小写上匹配的威胁中立名称重现了威胁明确名称产生的大部分转变（ GPT-5-mini上的11.00分中的8.54分）。

The results show that a security score measured under one representation may fail to generalize across threat-preserving representations of the same security problem. 结果表明，在一个表示法下测量的安全分数可能无法泛化相同安全问题的威胁保留表示法。

Robustness claims should therefore be supported by performance across a controlled set of threat-preserving representations rather than relying on a single representation-dependent score. 因此，稳健性声明应该由一组受控的威胁保留表示的表现来支持，而不是依赖于单一的表示相关分数。

A4 Dissecting model behavior through agent trajectories

arXiv: 2606.17454 AnthropicGoogleQwen

📝 中文摘要（中英对照）：

AI agent performance is not just a modeling problem, it is fundamentally a systems problem. 人工智能代理性能不仅仅是一个建模问题，它从根本上是一个系统问题。

The advanced capabilities of models are realized through agent harnesses. 通过代理线束实现模型的高级功能。

Therefore, a gap between model assumptions and harness behavior can easily prevent the model's full capabilities from translating into agent performance. 因此，模型假设和线束行为之间的差距很容易阻止模型的全部功能转化为座席绩效。

We formalize this as the `intent-execution' gap: the mismatch between what the model intends and what the harness executes, and vice versa. 我们将此形式化为“意图执行”差距：模型意图与线束执行之间的不匹配，反之亦然。

We argue that minimizing this intent-execution gap is as important as other aspects of harness design such as tools and execution loops. 我们认为，最大限度地减少这种意图-执行差距与线束设计的其他方面（如工具和执行循环）同样重要。

To illustrate the impact of this harness-model alignment, we develop a simple and customizable harness called `Simple Strands Agent' (SSA). 为了说明这种线束模型对齐的影响，我们开发了一种简单且可定制的线束，称为“Simple Strands Agent” （ SSA ）。

SSA aims to find the bulk of common patterns which generalize across different model families (such as Claude, Gemini, GPT, Grok, Qwen), as well as a small number of model-specific preferences. SSA旨在找到大量跨不同模型家族（如Claude、Gemini、GPT、Grok、Qwen ）泛化的常见模式，以及少数特定于模型的偏好。

We make two contributions: (i) we \textbf{reproduce or improve on the pass@1} performance reported by diverse model-provider families on popular agentic benchmarks (SWE-Pro, SWE-Verified, Terminal-Bench-2, and Deep-SWE), and (ii) building on an \textbf{analysis of 154\texttt{k} trajectories generated by SSA}, we look beyond the \texttt{pass@1} numbers which tend to be relatively even across frontier models. 我们做出了两项贡献： （ i ）我们\ textbf {复制或改进了不同模型提供者家族在流行的代理基准（ SWE-Pro、SWE-Verified、Terminal-Bench-2和Deep-SWE ）上报告的PASS @ 1}性能，以及（ ii ）基于\ textbf {对SSA生成的154\ texttt {k}轨迹的分析} ，我们超越了\ texttt {pass @ 1}数字，这些数字在前沿模型中往往相对均匀。

By representing agent trajectories in code state-spaces, we compute solution distance and backtracking to observe model-level differences in problem-solving behavior. 通过在代码状态空间中表示代理轨迹，我们计算解决方案距离和回溯，以观察模型级解决问题行为的差异。

Finer-grained metrics such as edit frequency, testing activity, and phase-transitions reveal how individual models allocate effort across different stages of problem solving. 更精细的指标，如编辑频率、测试活动和相变，揭示了各个模型如何在解决问题的不同阶段分配工作。

A5 Cogentic: Multi-Agent Orchestration for Automated Proof Discovery

arXiv: 2609.40324 GoogleAgentMulti-Agent

📝 中文摘要（中英对照）：

We present Cogentic, a multi-agent harness for automated proof discovery on open research problems.

While frontier language models can generate strong mathematical ideas in a single shot, single-shot generation is often insufficient for open problems that require exploring multiple competing conjectures, overcoming subtle technical obstructions, and retaining intermediate progress over a long horizon.

Cogentic addresses these challenges through an iterative prove-verify loop in which an orchestrator allocates a population of independent provers across distinct proof directions, subjects their output to adversarial verification by several specialized components, and promotes confirmed intermediate results into a persistent verified ledger that later rounds build on.

The harness is designed to be able to solve research-level math and theoretical computer science problems.

Using either Gemini 3.1 Pro or an early version of Gemini 4 Argon as the base model, Cogentic produced novel results on open problems across online learning, auction theory, and mechanism design.

Each result was independently verified by domain experts and is developed in full in companion papers.

We list these results, and new ones as they are verified, at https://sites.google.com/view/cogentic .

A6 How Do AI Agents Spend Your Money? Analyzing and Predicting Token Consumption in Agentic Coding Tasks

arXiv: 2604.22750 OpenAIAnthropicKimi

📝 中文摘要（中英对照）：

The wide adoption of AI agents in complex human workflows is driving rapid growth in LLM token consumption.

When agents are deployed on tasks that require a significant amount of tokens, three questions naturally arise: (1) Where do AI agents spend the tokens?

(2) Which models are more token-efficient?

and (3) Can agents predict their token usage before task execution?

In this paper, we present the first systematic study of token consumption patterns in agentic coding tasks.

We analyze trajectories from eight frontier LLMs on SWE-bench Verified and evaluate models' ability to predict their own token costs before task execution.

We find that: (1) agentic tasks are uniquely expensive, consuming 1000x more tokens than code reasoning and code chat, with input tokens rather than output tokens driving the overall cost; (2) token usage is highly variable and inherently stochastic: runs on the same task can differ by up to 30x in total tokens, and higher token usage does not translate into higher accuracy; instead, accuracy often peaks at intermediate cost and saturates at higher costs; (3) models vary substantially in token efficiency: on the same tasks, Kimi-K2 and Claude-Sonnet-4.5, on average, consume over 1.5 million more tokens than GPT-5; (4) task difficulty rated by human experts only weakly aligns with actual token costs, revealing a fundamental gap between human-perceived complexity and the computational effort agents actually expend; and (5) frontier models fail to accurately predict their own token usage (with weak-to-moderate correlations, up to 0.39) and systematically underestimate real token costs.

Our study offers new insights into the economics of AI agents and can inspire future research in this direction.

A7 Assessing Rule Adherence of LLM Adjudicators in Call of Cthulhu TRPG

📝 中文摘要（中英对照）：

As LLMs are increasingly deployed as autonomous adjudicators in games such as Call of Cthulhu (CoC), robust rule adherence becomes critical when user intent conflicts with system rules.

However, as these models are trained to be helpful and compliant, they may be vulnerable to a class of manipulations we term Rhetorical Injection, where adversarial users exploit narrative framing techniques such as pseudo-logical reasoning and authoritative coercion to bypass adjudication logic.

We present CoC-Seduce, a multi-agent adversarial benchmark built on CoC, a Tabletop Role-Playing Game (TRPG) in which rules are explicit about which risky actions require adjudication, yet interaction remains entirely in natural language.

Three LLMs, i.e., GPT-5.4, Claude Sonnet 4.6, Gemini 3.5 Flash, serve as adversarial generators producing 5,376 samples across 4 world settings and 16 skill categories.

We then benchmark 22 target adjudicators against this corpus.

Evaluation across 22 models reveals that neither newer releases nor explicit reasoning reliably confer adjudication robustness, that Pseudo-Logic framing is the most effective rhetorical style, and that the world setting, including culturally distant ones, has only a modest effect.

A9 Verify Before You Fix: Agentic Execution Grounding for Trustworthy Cross-Language Code Analysis

arXiv: 2604.10800 QwenAgentLLM
